Boleto do devedor

{% endblock %} {% block content %}

O boleto registrado (com PIX, quando o banco oferece) para o devedor pagar até o prazo-limite — que é o vencimento dele (CN-MA art. 925, § 4º). Quem gera a linha digitável, o código de barras e o PIX é o banco; o sistema não monta código de barras. A baixa é automática só quando tudo bate: valor igual ao do boleto, título aceitando pagamento e sem sustação. O resto vira pendência para alguém decidir.
