O sistema antigo guarda o id_path das imagens, mas ele não corresponde ao nome da pasta no disco — o caminho 1 aponta para 00000000, o 2 para 00000003. Como os nomes de arquivo são únicos entre as pastas, o sistema indexa por nome. O nome vem como 00003967.0001, onde o .0001 é o número da página e não extensão — no disco o arquivo costuma ser 00003967.0001.TIF. O sistema procura das duas formas, e sem distinguir maiúscula de minúscula.

Trazer para o acervo do sistema
Enquanto as imagens moram na pasta do sistema antigo, elas não são nossas. Desligar aquele sistema levaria as fichas junto, e o backup daqui não as alcança. Copiando para arquivos\ri\fichas, elas passam a viver onde o sistema roda e entram automaticamente no backup — que já varre essa pasta.
São cerca de 161 MB em 3.667 arquivos. Cada imagem recebe SHA-256 na cópia, para detectar corrupção depois. A operação é idempotente: rodar de novo só copia o que faltar.
